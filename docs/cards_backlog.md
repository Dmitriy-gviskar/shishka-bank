# Лесная коллекция — бэклог усилений (утверждён 21.07.2026)

Дополняет `cards_spec.md` (механика v2, экономика финализирована). Порядок = порядок работы.
Рамки, которые НЕ пересматриваем: одна валюта — шишки; шишки не за деньги; merge = 3 карты
одного существа одного грейда; коридор рынка 0.5–3× номинала; quicksell регрессивный;
бартер карта-на-карту отклонён.

## Фаза A — приоритет (максимум эффекта за минимум работы)

- [x] **A1. Ритуал эволюции при merge.** Сейчас прокачка — транзакция и обновлённый список.
  Три карты сходятся в центр, растворяются, вспышка в цвет нового ранга, новый арт «вылупляется».
  Переиспользовать движок `jackpotWalkout()` из вскрытия пака. Только клиент.
- [x] **A2. «Хочу» из пустой ячейки альбома + заявки на покупку.** Тап по несобранной ячейке →
  листинги именно этой карты; если их нет — оставить заявку («куплю ежа-эпик за 40»), продавец
  видит спрос. Замыкает петлю альбом → рынок, учит спросу и предложению. БД + сервер + клиент.
- [x] **A3. Титулы и лор по грейдам + фамильяр.** У каждого грейда своё имя-титул и фраза истории
  (лесенка читается как биография, а не светофор). Выбранная карта — питомец на главном экране,
  апнул грейд — питомец стал круче. БД (данные) + клиент.

## Фаза C — прокачка дублями

- [x] **C1. Топливо чужими картами.** Затык: пять разных дублей, ни одной тройки — прогресса нет.
  Добивать карту жертвой карт другого существа того же грейда по худшему курсу (2 своих + 4 любых).
  Свои всё равно выгоднее.
- [x] **C2. Обменная полка банка:** 5 любых карт грейда N → 1 случайная карта грейда N. Чистит мусор
  без второй валюты. ⚠️ Двигает экономику — пересчитать против `cards_economy_data.md`.
- [x] **C3. Merge никогда не проигрывает.** Рандом только вверх: редкий бонус «эволюция удалась
  вдвойне» (+1 грейд сверху или одна карта вернулась). Никакого шанса неудачи — дети.
- [x] **C4. Бейдж «осталась одна»** (2/3) на полке существа — крючок возврата, стоит копейки.
- [x] **C5. Предохранитель:** подтверждение, если сжигаемая карта единственная в альбомной ячейке
  (не сломать Panini-полку ради апгрейда).
- [x] **C6. След прокачки:** отметка «прокачана вручную», такие карты на рынке ценнее.

## Правила работы по бэклогу

- Разработка и тесты — на локальной `shishka_test`. Прод (`shishka_prod`) и деплой — только по явному
  «да»; фича скрыта до анонса (плитка убрана из forest.html, `collection.html.hidden`).
- Миграции только additive (`create or replace`, `add column if not exists`) — образец `db/cards.sql`.
- Каждый пункт проверяется своими глазами: rollback-транзакция для RPC, демо-страница в `cards/` для UI.
