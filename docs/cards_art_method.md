# Метод создания карточек-героев (РАБОЧИЙ, не переизобретать)

Единый источник правды по генерации арта коллекции. Пайплайн: `cards/gen_wave.py`
`beings_*.json` → `gen.sh` → Meshy `nano-banana-pro` (9 токенов/карта, 3:4). Ключ
`~/.config/shishka/meshy.key`. Каждое существо = 6 грейдов (common→gold), один код.

## Главный принцип: разнообразие живёт на ДВУХ осях одновременно

Провалить любую ось = однотипность. Обе провалить нельзя.

### Ось 1 — ВНУТРИ существа: ТРИ слоя прогрессии по грейдам (все обязательны)
Шесть карт одного существа растут от скромного к ослепительному. Три слоя в gen_wave.py:
- **`GRADE_STAGE`** — РАЗВИТИЕ ПЕРСОНАЖА: новичок → подмастерье → умелец → мастер →
  легенда → божество. Растут снаряжение, поза, статус, аура. Видно, что герой
  ПРОКАЧИВАЕТСЯ. Ступени универсальны, воплощение — из мира существа (через scenes).
  ⚠️ БЕЗ числовых меток «STAGE N/6» и слов-ярлыков капсом — nano-banana впаивает их
  надписью на карту (как «MYTHIC»/«TIER»). Только словесное описание.
- **`GRADE_COLOR`** — ДОМИНИРУЮЩИЙ ЦВЕТ грейда меняется (радуга рангов из эталона
  burunduk_v2: родной → циан-лайм → синий-тил → фиолет-магента → кислот-зелёный+оранж →
  золото-радуга). Даёт разноцветность шести карт. **Нельзя** держать одну палитру на все
  6 грейдов — карты сливаются («одинаковые по цвету», ошибка pro1/probe).
- масштаб/эпичность сцены растёт вместе со ступенью.

### Ось 2 — МЕЖДУ существами: разный мир + разный тон
- **`world`** — своя вселенная/профессия (кузнец, астроном, водолаз, рок-музыкант…).
  Грейды = рост В ЭТОЙ профессии, а НЕ единый RPG-класс «маг→рыцарь→бог» на всех
  (ошибка волн 1–10: 121 существо на одно лицо).
- **`tone`** — общий колорит существа, и он должен РАЗЛИЧАТЬСЯ между существами:
  не все тёмно-неоновые. Одно — светлое дневное, другое — ночное, третье — тёплый
  закат, четвёртое — холодный подводный, пятое — пастель, шестое — кислотный клуб.
  Тон задаётся в `tone`, а STYLE ему подчиняется (не навязывает неон всем).

## Константы, которые держим всегда
- Цвет-код ранга — **только на рамке** (`FRAME[]`, тонкий кант). В UI ранг ещё раз
  читается обводкой/свечением по `RAR[grade].color`. Поэтому арт свободен от rank-цвета.
- Узнаваемость существа сквозь 6 карт (`ident` + «same character across all six cards»).
- Свой **золотой финал** у каждого — НЕ крылатый ангел по шаблону.
- Формат 3:4, no-text, gacha/TCG-качество, cel-shading.
- **Анти-коллаж** (обязательно, иначе nano-banana лепит сетки мини-карт на epic/leg/gold):
  «ONE single full-bleed illustration, NO card-inside-card, NO multiple cards, NO grid/collage».
- **Сцены — статичный МОМЕНТ, не нарратив-движение.** Слова «dash / driving / racing / handing
  over / a sequence» модель читает как раскадровку и лепит серию кадров с подписями «Level 1/2/3».
  Если карта упорно коллажит даже после перегена — переписать сцену на портрет-момент:
  «holding X, standing still, a single close hero portrait». (Реальные случаи: свиристель-rare
  на санях и саламандра-legendary в огне коллажили по 5 раз, чинились только сменой на портрет-момент.)
- **ПРОФИЛАКТИКА (экономит токены):** legendary и gold сцены писать СРАЗУ портретами-моментами,
  а НЕ как action/масштаб («diving through an epic battle», «towering over an inferno») — именно
  они чаще всего коллажат и жгут перегены. Триггеры-слова избегать во всех грейдах:
  dash, driving, racing, diving, lunging, «many», «epic … battle/inferno/storm» как основа сцены.

## Формат существа в beings_*.json
```json
{
  "code": "vyhuhol", "name": "Выхухоль", "cat": "zver",
  "ident": "A cute but COOL cartoon Russian DESMAN, long trunk-snout, webbed feet, brave face.",
  "world": "deep-water exploration — diving, bathyscaphes, sunken ruins, bioluminescence",
  "tone": "cool deep-ocean blues and teal with warm gold glows (a dark, luminous underwater tone)",
  "scenes": ["<действие на common>", "…uncommon", "…rare", "…epic", "…legendary", "…gold — уникальный финал"]
}
```
`cat`: `zver` / `rastenie` / `nasekomoe` (птицы, рыбы, амфибии = `zver`).
Сцены описывают ДЕЙСТВИЕ/сюжет грейда в мире; энергию/яркость добавит GRADE_ENERGY,
тон добавит `tone` — в сценах цвет ранга НЕ упоминать.

## Процесс волны
1. Волнами по ~8–10 существ (не 40 разом — к концу скатишься в шаблон).
2. Подобрать существам РАЗНЫЕ миры И разные тона (проверить: не все ли тёмные/неоновые).
3. Запуск: `python3 cards/gen_wave.py cards/beings_waveN.json 8` (в фоне; ~1 мин на 60 карт).
4. **Контроль качества обязателен** (свои глаза): контактный лист PIL по грейдам +
   лист «одно существо = ряд из 6». Отсев брака (коллаж/текст/карта-в-карте) — удалить
   их png, перезапустить gen_wave (пропустит готовые, перегенерит удалённые). Проверять
   ВСЕ грейды, коллажи чаще на rare/epic/legendary.
5. **Показать заказчику РЕАЛЬНО**: `open <лист>.png` (Preview на маке). Просмотр через
   инструмент чтения изображений видит только ассистент — заказчик его НЕ видит.

## История ошибок (чтобы не повторять)
- ❌ Акварель/«детская книжка» — отвергнута Дмитрием. Нужен gacha/кислота/яркость.
- ❌ Волны 1–10: единый RPG-шаблон «малыш→маг→рыцарь→бог» + `dominant card color=ранг`
  → однотипность МЕЖДУ существами и одинаковая палитра грейдов у всех.
- ❌ Волна pro1: убрал прогрессию грейдов («one palette across all grades») → монотонность
  ВНУТРИ существа, «одинаковые по цвету». Починка = этот метод (обе оси сразу).
- ❌ Показ через чтение-изображения вместо `open` — заказчик ничего не увидел.
