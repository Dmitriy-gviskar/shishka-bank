# Беклог чата

## ✅ Стикеры
Сетка лесных эмодзи 🦊🐿️🦉🐻🦌🐰🌲🍄🌰🍂🌟❤️🔥😂👍🎉 в чате.
Отправляются как `type: 'sticker'`, отображаются крупно без пузыря.

## ✅ Статус «в лесу»
Зелёная точка на аватарке — человек был онлайн в последние 5 минут.
Поле `last_seen` в users, обновляется при каждом API-запросе, отдаётся в `/api/chat/list` как `online: true/false`.

## ✅ Реакции
Долгий тап на сообщение → пикер ❤️🔥😂👍😢. Повторный тап по той же реакции убирает её.
Таблица `message_reactions`, endpoint `/api/message/react`, реакции вложены в ответ `/api/chat`.

## ✅ Push-уведомления
При отправке сообщения получатель получает push-уведомление. Service worker показывает «Имя: текст».
Клик по уведомлению → открывает чат. Требует HTTPS и разрешения на уведомления.

## ✅ Голосовые сообщения
Зажал 🎤 → говоришь → отпустил → аудио отправляется. Плеер в чате. WebM в uploads/.

## ✅ Ответ на сообщение
Свайп вправо на сообщении → зелёная полоса «↩ Имя: текст» над полем ввода.
Отправленное сообщение содержит цитату. reply_to в БД, каскадное удаление при удалении исходного.

## ⏳ Стикер-подарок
Отправить стикер + 1 шишку вместе.
Нужно: совместить `/api/message` + `/api/transfer` в одном запросе.

## ⏳ Лесной почтальон
Достижение за N отправленных сообщений.
Уже есть `check_achievements` в `send_message` — нужно добавить achievement в каталог.

# 🏛 Большая идея: Шишка Банк как «Лесной Duolingo»

Приложение про взросление, замаскированное под игру. Петля: дело → шишки → впечатление → хочу ещё.

## ⏳ Фаза 1: Лесные курсы
Цепочки заданий по темам. Прогресс-бар курса. Значок по завершению.
- 🌱 Росток (4-7 лет): базовые навыки
- 🌿 Саженец (7-10): самостоятельность
- 🌲 Дерево (10-13): ответственность
- 🏛 Дупло мудрости: спецкурсы
Нужно: таблицы `courses` + `course_tasks`, UI курсов, назначение родителем.

## ⏳ Фаза 2: Визуальное дерево
Дерево растёт в реальном времени: новый лист за задание, золотые ветки за курсы.
Сезонная смена облика. Лесная поляна с деревьями всех детей круга.
Нужно: система ассетов дерева, генерация/апдейт по прогрессу.

## ⏳ Фаза 3: Лесной Дух как персонаж
Полноценный наставник: сюжетные квесты, реакция на прогресс, кастомизация (шляпы/плащи).
Добрая альтернатива пассивно-агрессивной сове Duo.
Нужно: диалоговая система, скины Духа, квестовые цепочки от лица Духа.

## ⏳ Фаза 4: Гильдии и кооперативные челленджи
Командные задания без выбывания. «Лесные повара», «Чистый лес».
Нужно: групповая система заданий, общий прогресс-бар гильдии.

## ⏳ Фаза 5: Лесная энциклопедия
Карточки существ открываются через курсы и задания.
Сейчас карточки из паков — добавить связку «прошёл курс → получил особую карту».
Нужно: привязка карт к курсам/достижениям.

## Философия
- Без стресса и лиг на выбывание — только рост
- Реальные дела, а не тыканье в экран
- Родительский контроль вместо алгоритма
- Лесная эстетика вместо пластикового flat-дизайна
