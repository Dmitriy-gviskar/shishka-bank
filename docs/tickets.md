# Бэклог: план развития Шишка Банк

Источник: «шишка банк план развития.docx» (Берёза). Статусы ниже — живые.

## P0 — сейчас

- [x] **T1** Кабинет ведущего не открывается с общей ссылки. PIN обязателен. Начисление не больше 100 шишек за раз.
- [x] **T2** Котлы: кнопка «Удалить» только владельцу.
- [x] **T3** Игры с питомцем: −1 шишка за ошибку; блиц не выкидывает после ошибки.
- [x] **T4** Кнопка «фото»: выбор из галереи, не только камера.
- [x] **T5** Задания: убрать дубли ведущего; не больше ~10 на день; очередь проверки не должна расти без конца.
- [x] **T6** Веб: своё дерево открывается с другого гаджета (сессия / код / восстановление).

## P1 — среднесрок

- [x] **T7** Список заданий для Берёзы.
- [x] **T8** Обмен картами: запрос только на равный ранг или ниже.
- [x] **T9** Два списка: ежедневки (дёшево) и «задание дня» (дороже, ротация).
- [x] **T10** Задания у родителей, не у ведущего: 3–5 своих (потолок 15) или выбор из каталога + «ок».
- [x] **T11** Магазин: править название/цену, несколько товаров, удалять товар и лавку.
- [x] **T12** Мини-задачи и викторины для 10–14 лет.
- [x] **T13** Офлайн: прокачка карт, паки, достижения без сети.

## P2 — перспектива

- [x] **T14** Гильдии: пригласить + пуш «собираемся», без захода в гильдию.
- [x] **T15** Монетизация: персонажи / апгрейды / шишки за деньги — схема в `docs/monetization.md` (кассы нет; шишки за рубли закрыты).
- [x] **T16** Магазин как Авито: резерв → «Отдал» → «Получил» → выплата.
- [x] **T17** Коллекции открывать пачками по 10, не все сразу.
- [x] **T18** Покупка видна в ленте покупателя.
- [x] **T19** Апгрейд карт кроме эволюции: дубль селится собирать 1🌰/день (не больше 5).
- [x] **T20** Обменная полка: выбрать, какие карты отдаёшь.
- [x] **T21** Новые персонажи: обитатели поляны за шишки (не пак, не касса). Журавль, цапля, утка, гусь, лебедь, трясогузка, морошка, клюква, можжевельник, корюшка, судак, форель, сокол, голубь, зяблик, тетерев, куропатка, вальдшнеп, кулик, подберёзовик, опёнок, сыроежка, ласточка, скворец, воробей, чомга, чайка, ястреб.
- [x] **T22** Родительский контроль: возраст тех, с кем можно общаться.
- [ ] **T23** Обмен 1 высшего ранга на 1 низшего.

## Веб — боль Берёзы

- [ ] **T24** Больше 6 лесных заданий; приветственные шишки; не ждать ведущего на каждое дело.
- [ ] **T25** Поиск друзей: список обитателей, заявка, одобрение. Не только код из мессенджера.
- [ ] **T26** Лесная поляна: вёрстка на ноуте.
- [ ] **T27** Веб не пустой: котлы, советы, гильдии, лавки, почта.
- [ ] **T28** Вкладка «новые» карты скроллится на ноуте.
- [ ] **T29** Подарить карту другу (в т.ч. «Берёза»).
- [ ] **T30** Рынок / подарок / чужая коллекция работают между друзьями, не только «себе».
